## Overview

A collection of end-to-end supply chain analytics projects built on the 
M5 Walmart forecasting dataset — progressing from Excel-based exploration 
to machine learning and automated replenishment planning.

All work, queries, notebooks, and dashboards are available in this repo. 
Feel free to explore, reference, or build on top of it.

---

## Dataset

**M5 Forecasting Competition Dataset — Walmart Retail Sales**

| File | Description |
|------|-------------|
| `sales_train_validation.csv` | Daily unit sales per product per store (1,913 days) |
| `sell_prices.csv` | Weekly sell price per product per store |
| `calendar.csv` | Dates, holidays, events, and SNAP day flags |
| `sales_train_evaluation.csv` | Validation + 28 extra days (used in Project 4) |

| | |
|---|---|
| Stores | 10 Walmart stores |
| States | California, Texas, Wisconsin |
| Products | 3,049 unique items |
| Categories | Foods, Hobbies, Household |
| Time Period | 2011–2016 (1,913 days) |

> Raw data files are not stored in this repo.
> See [`Data/README.md`](./Data/README.md) for download instructions.
